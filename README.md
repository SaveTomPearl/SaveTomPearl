# Save Tom Pearl

Неофициальная статическая веб-страница, посвящённая истории Тома Перла и призывающая учитывать контекст за популярными интернет-клипами. Проект собран на чистом HTML и CSS и предназначен для размещения через GitHub Pages или любой обычный статический хостинг.

> [!IMPORTANT]
> Эта страница **неофициальная** и не связана с Томом Перлом или GoFundMe. Информация в исходниках могла устареть или содержать неточности. Перед пожертвованием необходимо самостоятельно проверить организаторов и описание кампании.

## Страницы и возможности

- Информационный блок о жизни Тома Перла
- Исторический контекст и описание фактов из публичных источников
- Галерея изображений
- Баннер и ссылка на сбор средств
- Прямое предупреждение о необходимости верификации кампании
- Простое оформление без JavaScript и сторонних зависимостей

## Технологии

- HTML5
- CSS3
- Изображения в форматах JPG, PNG, WEBP и SVG

## Локальный запуск

Для просмотра нужна только возможность открыть HTML-файл в браузере:

```bash
git clone https://github.com/SaveTomPearl/SaveTomPearl.git
cd SaveTomPearl
```

Затем откройте `index.html` в браузере либо запустите простой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.

## Размещение на GitHub Pages

1. Откройте **Settings** репозитория.
2. Перейдите в раздел **Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.
5. Сохраните настройки.

Сайт будет доступен по адресу GitHub Pages вашего репозитория после публикации.

## Вклад в проект

Предложения по исправлению текста, стилизации и доступности страницы приветствуются:
